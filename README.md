# LEGACY Wrestling Cards v0.4.0

Possession and typed-reversal match engine prototype.

- The wrestler in control may keep playing offensive cards.
- Strike, Grapple, Aerial, Submission and Control attacks require matching reversal cards.
- A successful reversal transfers possession.
- During CPU possession, matching reversal cards become the player's defensive choices.
- If the player has no matching reversal, the CPU attack resolves automatically.
- When no offensive card is playable, Pin / Pass ends the sequence; against a vulnerable opponent it becomes a real pin attempt.
- Unique-card hand rules and mobile single-screen layout are retained.
